 Документация разработчика проекта парсинга (ChipDip)

## 1. Архитектура приложения
Проект представляет собой автоматизированный веб-скрапер на основе Python и Selenium WebDriver (конкретно Microsoft Edge).
Его основная задача — обход системы защиты от ботов (включая DDoS-Guard и SmartCaptcha от Yandex), сбор данных о товарах из заданных категорий и сохранение их в структурированном виде (JSON).

### Основные компоненты:
- **Драйвер браузера (Edge):** Используется для рендеринга страниц, выполнения JavaScript и имитации реального пользователя.
- **Модуль обхода защиты:** Обнаружение страниц с проверкой браузера (Cloudflare / DDoS-Guard), клик по чекбоксам, а также интеграция с `twocaptcha` для прохождения сложных форм капчи (SmartCaptcha/hCaptcha).
- **Пул прокси-серверов:** Скрипт поддерживает загрузку списка прокси (с авторизацией) из `PROXIES` в `.env`. Ротация прокси происходит при неудачных попытках загрузки или прохождения защиты.
- **Парсер данных:** Извлечение информации (название, цена, характеристики, ссылки на изображения) с помощью `XPath` и `CSS`-селекторов (методы Selenium `.find_element`).
- **Модуль сохранения:** Запись результатов в файлы `JSON` для дальнейшей обработки.

## 2. Ключевые классы и функции

### Структуры данных
- `ProductData` (dataclass): Хранит структурированную информацию о спарсенном товаре (имя, артикул, цена, характеристики и прочее).

### Основные функции
- `_parse_proxies()` -> list: Парсит строку с прокси-серверами из `.env` и возвращает список доступных прокси.
- `get_element_data(driver, selector)` -> str: Извлекает текстовые данные элемента по заданному CSS селектору.

### Класс `ChipDipScraper`
Главный класс для координации процесса парсинга.
- `setup_driver(self)`: Инициализирует и возвращает экземпляр `webdriver.Edge`. Настраивает необходимые опции (размер окна, user-agent) и подключает прокси (via extensions для аутентификации).
- `switch_proxy(self, driver)`: Выполняет ротацию прокси-сервера. Если прокси недоступны, процесс может завершиться с ошибкой.
- `is_browser_check(self, driver)`: Проверяет наличие iframe элементов защиты от ботов или капчи.
- `wait_for_browser_check(self, driver)`: Имитирует действия пользователя для прохождения проверок, решает капчи с помощью API TwoCaptcha.
- `parse_category_page_range(self, ...)`: Циклически обходит страницы категории, собирая список товаров и переходя на страницы их деталей.
- `run(self)`: Точка входа в процесс парсинга.

## 3. Интерфейсы взаимодействия
- **Входные данные:** URLs категорий сайта ChipDip вводятся пользователем через консоль.
- **Конфигурация (Environment):** 
  - `TWOCAPTCHA_API_KEY`: API ключ сервиса решения капч.
  - `PROXIES`: Список прокси в формате `ip:port:user:pass, ...`.
- **Выходные данные:** Файлы в формате `JSON` сохраняются в папку `data/results/`.

## 4. Требования для развертывания
- Установленный браузер Microsoft Edge и соответствующий ему Edge WebDriver.
- Python 3.10+
- Запуск `pip install -r requirements.txt`.
- Для Linux сред может потребоваться `Xvfb` для корректной работы браузера с графическим интерфейсом.
